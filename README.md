# Zhaoyang Liu's academic homepage

This site uses the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and is published at <https://zhy-liu.github.io/>.

- Edit `_pages/about.md` for the biography and homepage content.
- Add Markdown files to `_posts/` for blog entries. The blog page is intentionally empty for now.
- Edit or add files in `_publications/` for publications. The initial four entries were taken from [Google Scholar](https://scholar.google.com/citations?user=Fdtto0wAAAAJ&hl=en) on 1 October 2026.
- Edit `_config.yml` for profile information and `_data/navigation.yml` for the menu.

The site keeps the Academic Pages template's MIT license in `LICENSE`.
